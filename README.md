# python-attendance-tracker
A command_line tool written in python to help university students track courses absences against the 20% limit and generate a semester summary.
## FEATURES
- **Absence & Limit Calculations :** Computes absence percentage and remaining allowed hours.
- **Risk Status Alerts :** Categorizes each course into "SAFE" , "WARNING" , or "DANGER".
- **Semester Summary :** Logs multiple courses and prints a final attendance report.
